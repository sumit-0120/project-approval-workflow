## Installation Steps

1. Clone the repository

git clone https://github.com/sumit-0120/project-approval-workflow.git

2. Install dependencies

composer install

3. Setup environment

copy .env.example .env

4. Generate key

php artisan key:generate

5. Run migrations

php artisan migrate

6. Run Seeder

php artisan db:seed

7. Start the server

    php artisan serve
